# HazardBar

Signature motif: -45° hazard stripe, `--hazard-yellow` on `--hazard-black`, 8px/16px repeat, 6px tall, 0.7 opacity.

```html
<div class="hazard-bar"></div>
```

Rules: used as a section/footer divider — one per screen, full width. Never thicker than 8px, never vertical, never as a background fill.
