# Badges

Small meta chips for footers. Two kinds: `.version-badge` (grey, factual metadata like `v1.2.0`) and `.scope-badge` (amber, a promise/constraint like `COOKIES ONLY`).

```html
<span class="badge version-badge">v1.2.0</span>
<span class="badge scope-badge">Cookies only</span>
```

Rules: footer only, 10px, wide-tracked. Amber badges state guarantees, never warnings — warnings belong to the StatusPill.
